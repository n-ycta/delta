# Media / рабочие столы: проверка переделки

## Архитектура

- Все сущности остаются плагинами. Интерфейс — возможность плагина, отображаемая бейджем в общем списке.
- Media 0.3.3 — единый интерфейс и сервис API. YouTube/SoundCloud/Spotify 0.2.1 — headless-провайдеры, без отдельных приложений/экранов в доке.
- Провайдеры обнаруживаются сервисом Media через `core.components`; поиск и разрешение ссылок проходят через сервисы провайдеров с исходными правами вызывающего.
- UI не получает токен Core. Web-брокер разрешает только точный список Media API; iframe изолирован отдельным origin. Установка пакетов проверяет SHA-256.

## Проверено

- UI `ed4f03f8`: полный Verify shared UI завершился успешно.
- Источники интерфейса плагина видны сразу в выборе источника виджета. Player/Queue сохраняются и восстанавливаются после перезагрузки.
- Разные панели одного Media работают одновременно с одним владельцем декодера. У вспомогательных панелей нет дублирующего нижнего плеера.
- Правая кнопка по пустому канвасу открывает меню добавления окна; resize доступен по краям. Есть Ctrl +/-/0, Ctrl+wheel и Space/middle-drag.
- Отдельно проверен скрытый док (не только режим без подписей).
- Фоновый iframe не перехватывает клики через заголовок/содержимое верхнего окна; край окна плеера доступен для изменения размера.
- Дашборд 2400×1600 при масштабе 50%: в sandbox при pan измерено 95 кадров, медиана и p95 интервала около 16.7 мс. Это не гарантия FPS на другом устройстве.
- Реальный WAV/WebM и RSS enclosure, восстановление позиции, локальный offline shell, RU/EN, мобильный layout: браузерные регрессии пройдены.
- Визуализатор получает реальный спектр декодируемого WAV, не синтетическую анимацию. Защищённые embed не предоставляют PCM для анализатора.
- Официальные пакеты провайдеров 0.2.1 и Media 0.3.3 установились через `packages.install` на отдельном Core 0.4.4. Media обнаруживает три провайдера под ограниченными сервисными правами.
- Официальный MCP-сервис + изолированный UI + реальный браузерный декодер: pause → play записи библиотеки → seek → pause прошли через scoped MCP.
- Прогресс/длительность/seek внешних плееров проверены протокольными тестами с проверкой source/origin. Это НЕ подтверждение доступности звука у внешнего сервиса.
- Новый Web-релиз внесён в реестр обновлений после проверки архива, manifest и SHA-256. Добавлена автоматическая синхронизация записи Web.

## Не выдавать за завершённое

- Внешний звук YouTube не подтверждён: тестовый live URL оказался недоступен, другие проверенные видео вернули ошибку embed 150. Ограничения правообладателя/сервиса не обходятся. Разрешение ссылки и открытие iframe не равны воспроизведению.
- Поиск SoundCloud/Spotify требует собственных разрешённых credentials в настройках соответствующего провайдера. Spotify embed имеет ограничения аккаунта/preview; публичного управления громкостью у iframe API нет, поэтому общий slider для него отключён.
- Нативные codec/background/audio-session и внешние embed на Linux/Windows/Android не прошли проверку на физических устройствах.
- Поиск в окне браузера Studio направляет запрос в поисковик; совместимость сторонних сайтов с iframe/X-Frame-Options не гарантируется. Studio не является полноценным браузерным движком.
- Медиафайлы из IndexedDB не синхронизируются между устройствами. Metadata uploads батчируются, но очень большие отдельные metadata/очереди/плейлисты всё ещё упираются в предел JSON IPC 64 KiB.
- Готовый релиз не означает, что он уже установлен на пользовательском узле. UI Media и process Media — две части одного плагина, обновляемые в своих хосте/узле. Нативные бинарники не заменяются автоматически установленным клиентом.
